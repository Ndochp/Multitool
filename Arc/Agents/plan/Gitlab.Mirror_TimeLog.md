# Задачи: Команды GitlabTimeLog

## Описание
Данный документ содержит перечень задач по созданию команд для обработки GitlabTimeLog. Каждая команда будет обеспечивать определённую функциональность для работы с GitLab API через фасад ИнтеграцияGitlab.

## Реквизиты обработки GitlabTimeLog - Предложение по переименованию

### Текущие реквизиты:
| Текущее имя | Новое имя | Описание |
|-------------|-----------|----------|
| userID | ПользовательID | ИД пользователя в GitLab |
| After | После | Параметр даты (после) |
| Date | ДатаЗапроса | Дата запроса |
| BaseURL | БазовыйURL | URL GitLab сервера |
| Токен | ТокенДоступа | Токен доступа к GitLab API |

### Реквизиты табличной части "Таймлог":
| Текущее имя | Новое имя | Описание |
|-------------|-----------|----------|
| ТаймлогИД | ЗаписьТаймлогИД | ИД записи таймлога в GitLab |
| IssueIID | ЗадачаIID | IID задачи в GitLab |
| Project | ПроектПуть | Путь к проекту |
| Summary | ОписаниеРаботы | Описание работы |
| Duration | ДлительностьСек | Длительность в секундах |
| Date | ДатаРаботы | Дата выполненной работы |
