# Задачи на разработку «ЛистУчетаРабочегоВремени» (TDD)

## Обзор

Документ «ЛистУчетаРабочегоВремени» — ядро подсистемы таймтрекинга. Обеспечивает учёт интервалов рабочего времени работника с автоматической синхронизацией во внешние системы через ФасадИнтеграции.

**Ключевой принцип:** документ не содержит HTTP-вызовов и не знает о конкретных внешних системах. Все операции синхронизации выполняются через `ФасадИнтеграции`.

> 📄 **Развёрнутые описания задач ЛУР-001..ЛУР-014 (с юнит-тестами) перенесены** в сводный документ `Arc/Agents/plan/ТаймтрекингЗадачиРазработки.md` (раздел «Развёрнутые описания задач ЛистУчетаРабочегоВремени»). Ниже остаются только сводные справочные таблицы.
