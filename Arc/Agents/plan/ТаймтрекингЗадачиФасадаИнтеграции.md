### Жизненный цикл

1. **Создание ФасадаИнтеграции** — создаётся обработка сессии фасада для одного пользователя
2. **Первый вызов метода фасада** (например ДобавитьЗаписьОВремени) — фасад определяет ТипВнешнейСистемы по Задача.ВнешняяСистема.ТипСистемы
3. **Проверка кэша подключений** — если обработка подключения для данного типа системы уже создана в контексте сессии — используется существующая
4. **Создание обработки подключения** — если не найдена, фасад создаёт обработку «Подключение{ТипСистемы}» (контекст подключения)
5. **Создание обработки интеграции** — обработка подключения порождает обработку «Интеграция{ТипСистемы}» (контекст интеграции) с данными подключения и авторизации
6. **Вызов метода интеграции** — фасад делегирует вызов обработке интеграции
7. **Завершение сессии фасада** — все обработки подключения и интеграции уничтожаются
