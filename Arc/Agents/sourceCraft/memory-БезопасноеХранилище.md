# БезопасноеХранилищеДанных — Принципы работы

## Общая архитектура

Конфигурация 1С:Предприятия предоставляет два регистра сведений для безопасного хранения данных:

1. **`РегистрыСведений.БезопасноеХранилищеДанных`** — общие данные (доступны всем владельцам)
2. **`РегистрыСведений.БезопасноеХранилищеДанныхОбластейДанных`** — данные с разделением по областям (для каждого владельца изолированно)

### Выбор хранилища

```bsl
// Из ОбщегоНазначения/Ext/Module.bsl:
ИмяБезопасногоХранилищаДанных = "РегистрСведений.БезопасноеХранилищеДанных";
Если РазделениеВключено() И ДоступноИспользованиеРазделенныхДанных() И ОбщиеДанные <> Истина Тогда
    ИмяБезопасногоХранилищаДанных = "РегистрСведений.БезопасноеХранилищеДанныхОбластейДанных";
КонецЕсли;
```

## Структура регистра сведений

### Измерения
- **Владелец** — ссылка на объект, которому принадлежат данные (необходимый параметр)

### Ресурсы
- **Данные** — ХранилищеЗначения (содержит произвольные данные со сжатием)

## API из ОбщегоНазначения/Ext/Module.bsl

### Запись данных: `ЗаписатьДанныеВБезопасноеХранилище(Владелец, Данные, Ключ = "Пароль") Экспорт`

**Параметры:**
- `Владелец` — ссылка на объект-владелец данных (любой ссылочный тип)
- `Данные` — произвольные данные для хранения (структура, массив и т.д.)
- `Ключ` — строка, ключ в хранимой структуре (по умолчанию "Пароль")

**Алгоритм:**
1. Создаёт менеджер записи: `РегистрыСведений.БезопасноеХранилищеДанных.СоздатьМенеджерЗаписи()` или `...ОбластейДанных`
2. Вызывает `Прочитать()` для загрузки существующих данных владельца
3. Если запись найдена — извлекает данные: `БезопасноеХранилищеДанных.Данные.Получить()`
4. Дешифрует хранимые данные через `РасшифроватьСтроку(СохраненныеДанные, КлючВладельца)`
5. Записывает новые данные в структуру
6. Сжимает: `Новый ХранилищеЗначения(ДанныеДляСохранение, Новый СжатиеДанных(6))`
7. Шифрует: `ЗашифроватьСтроку(ДанныеДляХранилищеЗначения.Получить(), КлючВладельца)`
8. Записывает в регистр: `БезопасноеХранилищеДанных.Записать()`

### Чтение данных: `ДанныеИзБезопасногоХранилища(Владельцы, Ключи, ОбщиеДанные)`

**Параметры:**
- `Владельцы` — Массив владельцев (ссылки на объекты)
- `Ключи` — Строка с ключами через запятую (например "Логин,Пароль") или Неопределено для всех данных
- `ОбщиеДанные` — Булево (влияет на выбор регистра)

**Возвращает:** Соответствие(Владелец → Данные)

**Алгоритм:**
1. Формирует запрос к регистру:
```sql
ВЫБРАТЬ
    БезопасноеХранилищеДанных.Владелец КАК ВладелецДанных,
    БезопасноеХранилищеДанных.Данные КАК Данные
ИЗ
    #ИмяБезопасногоХранилищаДанных КАК БезопасноеХранилищеДанных
ГДЕ
    БезопасноеХранилищеДанных.Владелец В (&Владельцы)
```
2. Выполняет запрос и обрабатывает результаты
3. Для каждого владельца извлекает данные: `РезультатЗапроса.Данные.Получить()`
4. Дешифрует через `РасшифроватьСтроку(СохраненныеДанные, КлючВладельца)`
5. Если ключи указаны — возвращает только указанные поля структуры

## Использование в криптографии (СервисКриптографииDSSСлужебныйКлиент)

БезопасноеХранилищеДанных используется как источник настроек для DSS:
- **ИсточникНастроек** — Строка, определяет способ хранения сессионных настроек
- Использует регистр "БезопасноеХранилищеДанных" для хранения криптографических ключей

## Паттерн использования для интеграции GitLab

Для хранения токена GitLab в ObjectModule.bsl:

```bsl
// Запись токена
Процедура ЗаписатьТокенGitLab(Владелец, Токен)
    Данные = Новый Структура("Токен", Токен);
    ЗаписатьДанныеВБезопасноеХранилище(Владелец, Данные);
КонецПроцедуры

// Чтение токена
Функция ПрочитатьТокенGitLab(Владелец) Экспорт
    Результат = ДанныеИзБезопасногоХранилища(Нов Массив(Владелец), "Токен", Ложь);
    Если Результат.Количество() > 0 Тогда
        Возврат Результат[Владелец];
    КонецЕсли;
    Возврат Неопределено;
КонецФункции
```

## Важные моменты

1. **Данные всегда хранятся в ХранилищеЗначения** — нельзя сохранить произвольный тип напрямую
2. **Сжатие данных включено** (`Новый СжатиеДанных(6)`)
3. **Ключ по умолчанию "Пароль"** — можно изменить при вызове
4. **Владелец должен быть ссылкой** на метаданный объект
5. **При разделении данных** автоматически выбирается изолированное хранилище
