# Memory: Архитектурные ограничения 1С, правила проекта и yaxunit

## Ключевое правило: Общие модули 1С НЕ хранят состояние

В платформе 1С:Предприятие общие модули (CommonModules) являются stateless — переменные уровня модуля (`Перем`) не сохраняются между вызовами в разных контекстах (сервер/клиент, разные сеансы и т.д.). 

**НЕЛЬЗЯ** полагаться на `Перем` в общем модуле для хранения данных между вызовами.

## Правильный подход: Объектная модель через обработку

Для хранения состояния (URL, токен, настройки) нужно использовать **объект обработки** (DataProcessor):

1. Создать обработку (например, `ИнтеграцияGitlab`)
2. Добавить реквизиты объекта для хранения состояния (БазовыйURL, Токен)
3. Все методы API выносить в модуль объекта обработки
4. Инициализация: создать объект обработки, заполнить реквизиты, вызывать методы

```bsl
// Правильно:
Интеграция = Обработки.ИнтеграцияGitlab.Создать();  // .Создать(), не .СоздатьОбъект()!
Интеграция.БазовыйURL = "https://gitlab.example.com";
Интеграция.Токен = "glpat-abc123";
Результат = Интеграция.ПолучитьTimelogи(1, 42, "2024-01-01", "2024-01-31");
```

**Важно:** Для обработок (DataProcessor) используется метод `.Создать()`, а не `.СоздатьОбъект()`. `.СоздатьОбъект()` — для справочников, документов и других ссылочных типов.

## Применение к подсистеме GitLab.mirror

- Модуль `GitLab` (общий) — только вспомогательные утилиты без состояния (если нужны)
- Обработка `ИнтеграцияGitlab` — модуль объекта содержит все методы API и реквизиты для хранения URL/токена
- Модуль менеджера обработки `ИнтеграцияGitlab` — фабричные методы для создания экземпляров

## Правила yaxunit тестов

1. В модуле с тестами должна быть процедура `ИсполняемыеСценарии()` Экспорт, которая регистрирует тесты:

```bsl
Процедура ИсполняемыеСценарии() Экспорт

	ЮТТесты
		.ДобавитьТестовыйНабор("Банки")
			.ДобавитьТест("БИК")
			.ДобавитьТест("НомерСчета")
	;

КонецПроцедуры
```

2. Вызов ассертов yaxunit - `ЮТест.ОжидаетЧто(...)`, **не** `Ожидаем.Что(...)`.
3. Мокито - правильный API:
   - **Обучение**: `Мокито.Обучение(Модуль).Когда("ИмяМетода").Вернуть(Значение)` - модуль передаётся без кавычек (как ссылка), имя метода в кавычках (строка)
   - **Завершение обучения**: `.Прогон()` - запускает настроенное мокирование
   - **Проверка вызовов**: `Мокито.Проверить(Модуль).КоличествоВызовов("ИмяМетода").Равно(N)`
   - **Получение вызовов**: `Вызовы = Мокито.Проверить(Модуль).Вызовы("ИмяМетода")` - возвращает массив, где `Вызовы[0].Параметры[0]` - первый параметр первого вызова
   - **Не путать**: `Вернуть()`, а не `ТогдаВозвратить()`; `Обучение(Модуль)`, а не `ПодменитьМодуль("Имя")`
4. HTTP-ответ для моков: `ЮТест.Данные().HTTPОтвет().УстановитьКодСостояния(200).УстановитьТело(ДвоичныеДанные)` - реализует интерфейс `HTTPОтвет`

## Шаблоны заимствованных методов (Mock-модули в тестовом расширении)

Для мокирования методов конфигурации через Мокито, в тестовом расширении нужно создать модуль с тем же именем, что и мокируемый модуль, и использовать шаблон `&Вместо`:

### Для функции:
```bsl
&Вместо("ИмяМетода")
Функция Мок_ИмяМетода(<ПараметрыМетода>)
	ПараметрыМетода = Мокито.МассивПараметров(<ПараметрыМетода>);
	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(<Объект>, "ИмяМетода", ПараметрыМетода, ПрерватьВыполнение);
	Если Не ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(<ПараметрыМетода>);
	Иначе
		Возврат Результат;
	КонецЕсли;
КонецФункции
```

### Для процедуры:
```bsl
&Вместо("ИмяМетода")
Процедура Мок_ИмяМетода(<ПараметрыМетода>)
	ПараметрыМетода = Мокито.МассивПараметров(<ПараметрыМетода>);
	ПрерватьВыполнение = Ложь;
	МокитоПерехват.АнализВызова(<Объект>, "ИмяМетода", ПараметрыМетода, ПрерватьВыполнение);
	Если Не ПрерватьВыполнение Тогда
		ПродолжитьВызов(<ПараметрыМетода>);
	КонецЕсли;
КонецПроцедуры
```

### Параметры:
- `<ИмяМетода>` — Имя мокируемого метода
- `<ПараметрыМетода>` — Параметры мокируемого метода (полная сигнатура)
- `<Объект>` — Объект-владелец метода:
  - Для **общих модулей** — ссылка на общий модуль (например, `КоннекторHTTP`). **Не использовать `ЭтотОбъект`**.
  - Для **объектов** (справочники, документы, обработки, формы) — `ЭтотОбъект`
  - Для **менеджеров** — ссылка на менеджер (например, `Справочники.Пользователи`)

### Пример для КоннекторHTTP.Get:
```bsl
&Вместо("Get")
Функция Мок_Get(URL, ПараметрыЗапроса = Неопределено, ДополнительныеПараметры = Неопределено, Сессия = Неопределено) Экспорт
	ПараметрыМетода = Мокито.МассивПараметров(URL, ПараметрыЗапроса, ДополнительныеПараметры, Сессия);
	ПрерватьВыполнение = Ложь;
	Результат = МокитоПерехват.АнализВызова(КоннекторHTTP, "Get", ПараметрыМетода, ПрерватьВыполнение);
	Если Не ПрерватьВыполнение Тогда
		Возврат ПродолжитьВызов(URL, ПараметрыЗапроса, ДополнительныеПараметры, Сессия);
	Иначе
		Возврат Результат;
	КонецЕсли;
КонецФункции
```

**Важно:** Не использовать `Мокито.ПерехваченныйВызов(...)` — это устаревший/неправильный подход. Правильный шаблон — через `&Вместо`, `Мокито.МассивПараметров`, `МокитоПерехват.АнализВызова` и `ПродолжитьВызов`.
