# GitLab TimeLog: Тесты GraphQL API

## Описание

Данный документ описывает текстовые (описательные) тесты для функций работы с GitLab GraphQL API.
Тесты предназначены для проверки корректности реализации в обработке `ИнтеграцияGitlab`.

---

## 1. Тесты GQL-Q001: Получение таймлогов пользователя за период

### Тест T-GQL-Q001-001: Успешное получение таймлогов
**Цель:** Проверить, что функция возвращает корректные данные при наличии таймлогов у пользователя.

**Подготовка:**
- Пользователь с ID=12345 имеет 5 записей таймлогов за период 01.01.2024 - 31.01.2024
- Токен доступа валиден
- Базовый URL настроен на тестовый GitLab

**Шаги:**
1. Вызвать `ПолучитьТаймлогиПользователяGraphQL(12345, "2024-01-01", "2024-01-31")`
2. Проверить, что возвращена ТаблицаЗначений с 5 записями

**Ожидаемый результат:**
- Возвращается ТаблицаЗначений
- Количество строк = 5
- Каждая строка содержит корректные данные: timeentry_id, duration, message, spent_at, project_name, issue_title и т.д.
- Типы данных колонок соответствуют спецификации
