## Сценарии использования
### Роль: Пользователь
1. Формы списка
    1. Может видеть список задач в виде иерархического списка
    2. Может видеть плоский список активных задач
    3. Может видеть детали задачи, на которой стоит курсор в списке
    4. Может редактировать детали задачи, на которой стоит курсор в списке
    5. Может создавать задачи как подзадачи, так и "соседние"
    6. Может собирать задачи в "папки", которые должны визуально выделяться в форме списка
    7. Может перемещать задачи драг-н-дропом, при этом если в группировке списка были группировки по значениям реквизитов (например срочности) то они должны измениться в соответствии с новым значением группировки при перетаскивании на группировку. При перетаскивании в иерархическом списке - просто меняется родитель.
    8. Непосредственное удаление задач - через БСП обработку удаления, в рамках ТУДШника инструменты не нужны
    9. Просроченные задачи в формах списка выделяются цветом.
    10. Для задач у которых в сроке указано время моментом просрочки является оно, у которых в качестве времени указано 00:00 - полночь следующей даты. 
    11. просроченность должна подсвечиваться динамически, а не только при открытии формы.
    12. Может видеть историю изменений задачи
    13. Может менять порядок задач в иерархическом списке (В активных - нет. Там будет какое-нибудь автовычисление порядка, но потом)
    14. Для улучшения наглядности можно пометить задачу и всех ее детей спец тегом, который будет выводиться в представлении. Если у каой-то из дочерних будет свой тег, то у ее детей должен выводиться тег от ближайшего родителя с заполненным тегом.
    15. может копировать/преремещать задачи в иерархическом списке: при копировнии в новом месте в качестве дочерней задачи должны создаваться копии копируемой задачи и всех дочерних задач. При этом выполненные/удаленные задачи должны создаться без признака выполненности и удаления. При перемещении просто меняется родитель.
2. Форма задачи
    1. может видеть список задач, которые блокируют текущую задачу (и редактивровать этот список)
    2. Может видть детей и родителей этой задачи, чтобы можно было быстро скакать по контексту
    3. Может видеть историю изменений задачи
    4. Может создать подчиненную задачу
    3. Для списков блокеров/родителей/детей кроме названия должно быть видно их состояние
    4. После сохранения задачи, если она была текущей в списке должны обновиться детали текущей задачи
    5. Может произвольно редактировать реквизиты:
        * Название
        * Описание
        * Срок
        * Категория срочности
        * Категория места
        * Код проекта
        * Признак папки
        * Признак решена
        * Дата начала
        * Квадрант (для любителей таблицы важно/срочно)

## Термины и описания объектов
### Активная задача
Это задача, к выполнению которой можно приступать немедленно. 
Активная задача - это задача, которая:
1. не является папкой, 
2. не имеет подзадач, 
3. не имеет нерешенных блокеров
4. не имеет решенных родителей.
5. не имеет даты начала в будущем
5. возможное развитие, пока не считается. Если будтут проекты в тудушнике, то принадлежит проекту в активном статусе или является блокером потенциально активной задачи. Этот пункт требует дальнейшего размышления.

### Папка
Задача, которая используется как группирующая, но не должна появляться в списке активных задач. и не должна блокировать активность своего родителя.


## Нефункциональные требования
1. Задачник должен работать быстро запись задачи при 800+ задачах меньше 0,5 секунд
2. Задачник должен работать быстро открытие задачи при 800+ задачах меньше 0,5 секунд
