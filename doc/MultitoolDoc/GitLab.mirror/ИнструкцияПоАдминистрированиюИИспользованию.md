# Инструкция по администрированию и использованию
## Набор фактов
* Токен пользователя будем хранить в безопасном хранилище, владелец - справочник ссылка на пользователей системы, если не найден, то пустая ссылка, ключ - ссылка (URL) на гитлаб сервер
* Для каждого сервера создается новый элемент в справочнике "ВнешниеСистемыТикетов" с типом "Гитлаб" (предопределенный)
* Issues  в гитлаб соответствуют справочнику Тикеты
* На данном этапе остальные сущности гитлаб отражаются на доп реквизиты справочника тикетов с префиксом GitLab
