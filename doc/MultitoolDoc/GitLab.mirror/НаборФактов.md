# GitLab.mirror — Набор фактов (модель данных)

Этот документ фиксирует ключевые решения по модели данных подсистемы GitLab.mirror. Перенесён из черновика `Arc/Agents/plan/Еще один список задач.md` (раздел «Набор фактов»).

## 1. Хранение токенов пользователей

- Токен пользователя хранится в **безопасном хранилище**.
- **Владелец** ключа — справочник «ВнешниеСистемы» (внешняя система).
- **Состав ключей** безопасного хранилища получается из функции подсистемы **Mirror** в зависимости от типа внешней системы.

## 2. Справочник внешних систем тикетов

- Для каждого GitLab-сервера создаётся новый элемент справочника «ВнешниеСистемыТикетов».
- Элемент имеет тип **«Гитлаб»** (предопределённый).

## 3. Соответствие объектов 1С и GitLab

- **Issues** в GitLab соответствуют справочнику **«Тикеты»**.
- На данном этапе **остальные сущности GitLab** отражаются на **дополнительные реквизиты** справочника «Тикеты» с префиксом **`GitLab`**.
