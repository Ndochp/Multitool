# GitLab.mirror — Интеграция с GitLab

## Обзор подсистемы

Изолированная библиотека для работы с GitLab API из конфигурации 1С. Обеспечивает синхронизацию времени из «ЛистаУчетаРабочегоВремени» в GitLab через Timelogs API, а также прямой просмотр и управление таймлогами.

**Принцип изоляции:** весь код работы с HTTP и GitLab API сосредоточен в этой подсистеме. Документ «ЛистУчетаРабочегоВремени» не содержит HTTP-вызовов, а взаимодействует только через ФасадВнешнихСистем.
