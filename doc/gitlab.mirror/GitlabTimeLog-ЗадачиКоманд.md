# Задачи: Команды GitlabTimeLog

## Описание
Данный документ содержит перечень задач по созданию команд для обработки GitlabTimeLog. Каждая команда будет обеспечивать определённую функциональность для работы с GitLab API через фасад ИнтеграцияGitlab.

## Реквизиты обработки GitlabTimeLog - Предложение по переименованию

### Текущие реквизиты:
| Текущее имя | Новое имя | Описание |
|-------------|-----------|----------|
| userID | ПользовательID | ИД пользователя в GitLab |
| After | После | Параметр даты (после) |
| Date | ДатаЗапроса | Дата запроса |
| BaseURL | БазовыйURL | URL GitLab сервера |
| Токен | ТокенДоступа | Токен доступа к GitLab API |

### Реквизиты табличной части "Таймлог":
| Текущее имя | Новое имя | Описание |
|-------------|-----------|----------|
| ТаймлогИД | ЗаписьТаймлогИД | ИД записи таймлога в GitLab |
| IssueIID | ЗадачаIID | IID задачи в GitLab |
| Project | ПроектПуть | Путь к проекту |
| Summary | ОписаниеРаботы | Описание работы |
| Duration | ДлительностьСек | Длительность в секундах |
| Date | ДатаРаботы | Дата выполненной работы |

## Список задач

### GITL-TL-001: Команда получения списка проектов пользователя
**Статус: Создана**
**Описание:** Реализовать команду для получения списка проектов, доступных пользователю в GitLab.
**Метод API:** GET /api/v4/projects?membership=true&state=active
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-002: Команда получения списка задач (Issues) пользователя
**Статус: Создана**
**Описание:** Реализовать команду для получения списка назначенных задач пользователя.
**Метод API:** GET /api/v4/users/{user_id}/issues?state=opened
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-003: Команда получения таймлогов для конкретной задачи
**Статус: Создана**
**Описание:** Реализовать команду для получения записей времени, затраченных на конкретную задачу.
**Метод API:** GET /api/v4/projects/{id}/issues/{issue_iid}/timelogs
**Параметры:** ПроектID, IssueIID, ДатаНач, ДатаКон
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-004: Команда инициализации соединения с GitLab API
**Статус: Создана**
**Описание:** Реализовать команду для настройки соединения с GitLab API (базовый URL и токен).
**Параметры:** БазовыйURL, ТокенДоступа
**Примечание:** Базовая команда, от которой зависят все остальные

### GITL-TL-005: Команда получения таймлогов сотрудника за период
**Статус: Создана**
**Описание:** Реализовать команду для получения всех записей времени сотрудника за указанный период.
**Метод API:** GET /api/v4/users/{user_id}/time_entries
**Параметры:** ПользовательID, ДатаНач, ДатаКон
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-006: Команда добавления записи времени (timelog)
**Статус: Создана**
**Описание:** Реализовать команду для создания новой записи затраченного времени.
**Метод API:** POST /api/v4/projects/{id}/issues/{issue_iid}/time_spent
**Параметры:** ПроектID, IssueIID, ДлительностьВСекундах, ДатаРаботы, Описание
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-007: Команда удаления записи времени (timelog)
**Статус: Создана**
**Описание:** Реализовать команду для удаления существующей записи времени.
**Метод API:** DELETE /api/v4/projects/{id}/issues/{issue_iid}/timelogs/{timelog_id}
**Параметры:** ПроектID, IssueIID, TimelogID
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-008: Команда получения статистики времени по задаче
**Статус: Создана**
**Описание:** Реализовать команду для получения статистики затраченного времени по задаче.
**Метод API:** GET /api/v4/projects/{id}/issues/{issue_iid}/time_stats
**Параметры:** ПроектID, IssueIID
**Зависимости:** GITL-004 (Инициализация)

### GITL-TL-009: Команда получения таймлогов за конкретную дату
**Статус: Создана**
**Описание:** Реализовать команду для получения записей времени сотрудника за одну конкретную дату.
**Метод API:** GET /api/v4/users/{user_id}/time_entries?date_on_or_after={date}&date_before={date+1}
**Параметры:** ПользовательID, Дата
**Зависимости:** GITL-TL-005

### GITL-TL-010: Команда преобразования данных из GitLab в локальный формат
**Статус: Создана**
**Описание:** Реализовать команду для приведения данных от GitLab API к единому внутреннему формату обработки.
**Входные данные:** JSON ответ от GitLab API
**Выходные данные:** ТаблицаЗначений с унифицированной структурой

### GITL-TL-011: Команда загрузки таймлогов в таблицу результата
**Статус: Создана**
**Описание:** Реализовать команду для заполнения табличной части "Таймлог" данными из GitLab API.
**Параметры:** ИсточникДанных, Фильтры
**Зависимости:** GITL-TL-003, GITL-TL-005

### GITL-TL-012: Команда валидации данных перед отправкой в GitLab
**Статус: Создана**
**Описание:** Реализовать команду для проверки корректности данных перед созданием/обновлением записей.
**Параметры:** ДанныеДляПроверки, ТипВалидации

### GITL-TL-013: Команда формирования отчёта по таймлогам
**Статус: Создана**
**Описание:** Реализовать команду для формирования сводного отчёта по загруженным таймлогам.
**Параметры:** ПериодНач, ПериодКон, ПользовательID

## Порядок выполнения задач
1. GITL-TL-004 (Инициализация) - базовая команда для всех остальных
2. GITL-TL-001 (Проекты) - получение списка проектов
3. GITL-TL-002 (Задачи) - получение списка задач
4. GITL-TL-010 (Преобразование данных) - подготовка к работе с данными
5. GITL-TL-003 (Таймлоги задачи) - основная функциональность
6. GITL-TL-005 (Таймлоги сотрудника) - расширенная функциональность
7. GITL-TL-009 (Таймлоги по дате) - производная от GITL-TL-005
8. GITL-TL-006 (Добавление записи) - запись данных
9. GITL-TL-007 (Удаление записи) - удаление данных
10. GITL-TL-008 (Статистика) - аналитика
11. GITL-TL-011 (Загрузка в таблицу) - интеграция с UI
12. GITL-TL-012 (Валидация) - проверка данных
13. GITL-TL-013 (Отчёт) - финальная агрегация
